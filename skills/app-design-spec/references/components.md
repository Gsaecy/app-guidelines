# 组件规格（components.md）

> 高度单位：桌面 px / 移动 pt-dp。所有尺寸为「视觉尺寸」，热区按平台规则放大。

## 操作类

| 组件 | 英文 | 高度 | 圆角 | 内边距 | 状态 | 常见错误 |
|---|---|---|---|---|---|---|
| 主按钮 | Primary Button | 32/40 | 8–10 | 15–22 | 默认/悬停/按压/禁用/焦点 | 文字溢出、圆角与容器不匹配 |
| 次按钮 | Secondary Button | 32 | 8–10 | 12–16 | 同上 | 与主按钮同权重 |
| 图标按钮 | Icon Button | 32×32 | 8 | 6–8 | 同上 | 热区只有图标大小 |
| 胶囊 CTA | Pill CTA | 40 | 999 | 20–24 | 同上 | 页面里出现两个胶囊主操作 |

## 输入类

| 组件 | 高度 | 圆角 | 说明 |
|---|---|---|---|
| 文本框 | 32–44 | 8 | label 必须存在；聚焦主色边框 + 3px 光晕；错误红框 + 行内文案 |
| 搜索框 | 32–36 | 999 或 8 | 左图标、有内容时右侧清除；输入即结果，不按回车才搜索 |
| 数字输入 | 32 | 8 | 步进器 24×24；输入即校验 |
| 下拉选择 | 32 | 8 | 展开层 8 + 层级 3 阴影；选项 ≥ 36 高；选中打勾 |
| 上传区 | ≥ 120 | 12 | 虚线 1.5px；写明格式与大小上限；支持拖拽 + 点击 |

## 选择类

| 组件 | 尺寸 | 规则 |
|---|---|---|
| 复选框 | 17×17 | 多选；点击区域 = 整行；勾选 120ms |
| 单选组 | 17×17 圆 | 互斥 2–5 项；必须有默认项；↑↓ 切换 |
| 开关 | 38×22 | 即时生效，不配保存；120–180ms |
| 滑块 | 轨道 4 / 拇指 20 | 拖动显示数值；步长取整 |
| 分段控件 | 28–32 | 2–5 项；选中实底 + 阴影；切换不加确认 |

## 导航类

| 组件 | 规格 | 规则 |
|---|---|---|
| 侧栏导航 | 行高 40 / 圆角 10 / 宽 216–280 | 选中：主色实底 + 白字；一级项 3–7 |
| 标签页 | 高 40 / 指示条 2px | 2–7 个；切换保留滚动位置 |
| 面包屑 | 13px | 3 层以上才出现；末项不可点；分隔符统一 |
| 分页 | 按钮 32×32 | 当前页实底；> 7 页折叠为 … |

## 数据展示

| 组件 | 规格 | 规则 |
|---|---|---|
| 卡片 | 圆角 12–18 / 内边距 16–24 | 一张卡一件事；悬停抬升 ≤ 3px |
| 列表行 | 高 40/48 | 左图标 20、右 chevron；分隔线 8% 前景 |
| 表格 | 行高 40 / 表头 12px 600 | 数字右对齐；100+ 行必须虚拟化 |
| 徽章 | 高 20–24 / 圆角 999 | 颜色只做辅助，必须配文字 |
| 头像 | 24/32/40/64 | 缺省首字母 + 稳定配色 |

## 反馈类

| 组件 | 规格 | 规则 |
|---|---|---|
| 进度条 | 高 6 / 圆角 999 | < 1s 不显示；只增不减 |
| Spinner | 16/20/32 | ≥ 1s 才出现；1000–1400ms 循环 |
| 骨架屏 | 同结构 | 不用假内容；1300ms 循环 |
| 提示条 InfoBar | 自适应 | 左图标 + 可关闭；不与 Toast 混用 |
| Toast | 高 32–40 | 2–4s 自动消失；只讲结果 |
| Tooltip | — | 延迟 300–500ms；≤ 60 字；不含交互 |
| 对话框 | 宽 360–560 | 遮罩 α .32–.5；主操作在右；Esc 关闭 |

## 状态与空态

| 组件 | 规则 |
|---|---|
| 空状态 | 图标 ≤ 96 + 一句说明 + 一个主操作；禁止只写「暂无数据」 |
| 步骤条 | 节点 24 / 连接线 2px；步骤 ≤ 5 |
| 错误态 | 字段级贴字段；表单级顶部汇总；页面级含「重试」 |
| 禁用态 | 降饱和 + 说明原因（tooltip / 行内文案） |

## 状态矩阵（每个可交互组件必须定义）

默认 Default → 悬停 Hover → 按压 Pressed → 焦点 Focus → 禁用 Disabled → 加载 Loading（可选）→ 错误 Error（表单类）。

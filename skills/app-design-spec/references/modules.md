## 01 品牌与视觉基础
必须定义：Logo 构造网格 / 安全区 ≥ 0.5×标识高 / 最小尺寸（数字 ≥ 24px，favicon 16px 单独简化）/ 横竖版与单色反白 / 品牌色 + 2 辅助色 + 语义色 / 字体栈与字号阶梯 / 图标体系 / 禁用示例。
常见错误：只交 PNG；深色模式品牌色发光。

## 02 应用图标与商店素材
必须出齐：
| 平台 | 尺寸 | 说明 |
|---|---|---|
| iOS | 1024（商店）/ 180 / 120 / 167 / 152 / 87 / 80 / 58 / 40 / 29 / 20 | 无 alpha、无自带圆角 |
| Android | 108dp 自适应（安全区 66dp）/ 512 商店 | 32 位 PNG |
| Windows | 44 / 150 / 310 / 宽图 310×150 / 商店 50 / 启动 620×300 | MSIX |
| macOS | 1024 → 16 | 系统自动圆角约 22.37% |
| Web | 16 / 32 / 180 / 192 / 512（maskable 安全区 40%） | favicon/PWA |
商店截图 3–8 张，首屏讲价值，含深浅色与说明文案。

## 03 启动与首次体验
闪屏 ≤ 2s 仅品牌露出；引导 3–5 屏可跳过有进度；权限先预请求说明收益；首启只教 1 件事；空账号给示例内容。

## 04 账户与身份
字段：手机号或邮箱二选一；密码 ≥ 8 位、可粘贴；验证码 6 位 / 60s 重发。
错误文案 = 发生了什么 + 怎么改（行内，不弹窗）。
第三方登录与「通过 Apple 登录」同等显著；提交中禁用防重复；会话过期可一键重登且不丢草稿；注销需二次确认 + 影响说明 + 冷静期。

## 05 导航与信息架构
一级入口 3–7（移动底部 ≤ 5）；选中态实底或指示条；搜索输入即结果 + 历史 + 空结果建议；面包屑 3 层以上；深链稳定。

## 06 内容浏览与列表
一张卡一件事；筛选排序分离并实时反馈数量；分页或无限滚动二选一且失败可重试；批量选择有明确模式与已选计数；空状态给出口。
性能：首屏图片 ≤ 12 张、每帧解码 3–6 张、列表重建用签名 diff、缩略图 300–500 LRU。

## 07 详情与操作
首屏 = 主视觉 + 标题 + 关键属性 + 主操作；主操作吸底，次操作进「更多」；媒体查看器支持缩放/键盘左右/Esc；分享含链接与复制；编辑离开前提示未保存。

## 08 商业化与交易
定价 ≤ 3 档、推荐档高亮、年付折算月价；价格与权益购买前完整可见（隐藏续费违规）；支付状态机（待支付/处理中/成功/失败/已退款）每态有出口；恢复购买、兑换码、试用齐备；订单/发票可查可退，退款回收权益；失败给原因与替代方式。

## 09 设置与账户管理
按主题分组、组内 ≤ 7；开关即时生效不配保存；危险操作置底 + 二次确认；通知未开给系统设置跳转；隐私页说明收集/用途/删除；关于页含版本/许可/联系方式；反馈预填版本与日志 ID。

## 10 系统集成
托盘/菜单栏常驻 + 退出；通知可关、点击直达；快捷键符合平台约定；文件关联与图标正确；自动更新静默下载 + 可看日志；多窗口状态独立。

## 11 状态、错误与恢复
四态（空/加载/错误/成功）全覆盖；错误分级（字段/表单/页面/全局）；离线可读缓存并标注；同步冲突三选一（本地/云端/合并）；崩溃恢复未保存内容；重试 1s/2s/4s 退避可取消。

## 12 无障碍、国际化与质量
对比度 4.5:1 / 大字 3:1；焦点环 2px；键盘顺序 = 视觉顺序；读屏名称完整；文案外置 +30% 膨胀；RTL 镜像；日期货币按 locale；深浅色与高对比都测；性能预算进验收；关键路径埋点与实验位。

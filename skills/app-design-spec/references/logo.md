# Logo 设计规范（logo.md）

> 目标：形状可复现、任意尺寸不变形、交付可直接进工程。在线演示：/logo.html

## 一、类型选择

| 类型 | 优点 | 风险 | 适用 |
|---|---|---|---|
| 文字标 Wordmark | 识别快、承载品牌名 | 长名字/多语言难处理 | 名称短且独特 |
| 字母标 Lettermark | 极简、缩小友好 | 需解释全称 | 名字长、缩写有辨识度 |
| 图形标 Pictorial | 跨语言、图标化 | 与功能图标混淆 | 有具象符号 |
| 抽象标 Abstract | 独占性强、易延伸 | 初期无含义需教育 | 科技/平台产品 |
| 徽章标 Emblem | 权威、可做印章 | 缩小丢细节 | 机构/赛事/认证 |
| 组合标 Combination | 图形 + 文字最完整 | 必须准备拆分布局 | 多数产品首选 |

## 二、几何构造（可选比例）

| 体系 | 数值 | 用途 |
|---|---|---|
| Φ 黄金比 | 1 : 1.618 | 主形与留白、标识与字距 |
| √2 白银比 | 1 : 1.414 | 等距缩放、纸张类比 |
| 1 : 2 | 倍数 | 图标网格、模块单元 |
| 三等分 | 1/3 · 2/3 | 辅助线、视觉重心 |
| 8 点网格 | 8/16/24/32 | 所有坐标取整 |
| 圆半径族 | R / 2R / 3R | 同标识内半径成倍数 |
| 描边单位 | 1/2/4 | 转角与切口统一 |

## 三、图案切割（Boolean Cutting）

**7 步流程**
1. 定画板：24/32/1024，1 单位 = 1 格
2. 定几何：只用圆、方、三角、直线，半径取整
3. 定比例：1:1、1:2、Φ、√2
4. 切形状：合并 / 减去 / 相交 / 排除
5. 调光心：光学居中
6. 加呼吸：切口 ≥ 1 单位
7. 转轮廓：描边转填充，锁 viewBox

**四种运算**
| 运算 | 结果 | 典型用法 |
|---|---|---|
| 合并 Union | 并集 | 组合两个基础形 |
| 减去 Subtract | A − B | 挖缺口、做负空间 |
| 相交 Intersect | A ∩ B | 取重叠区做新形 |
| 排除 Exclude | 异或 | 重叠区镂空 |

**可复现性要求**：写清「画板 + 网格 + 半径 + 布尔顺序」，例如「R=58 圆 − 116 方，切角 12」。写不出说明，就无法复现。

## 四、光学修正（必须做）

| 项 | 数值 |
|---|---|
| 圆 / 三角 overshoot | +1.5–2.5% |
| 文字视觉居中 | 上提 1–2% |
| 外转角半径 | ≥ 描边宽 |
| 16px hinting | 简化 ≤ 2 单位细节 |
| 横竖笔画差 | 横比竖细 5–8% |

判断：缩到 16px 后若某角消失或糊成一团，就是修正不足。

## 五、安全区与最小尺寸

- Clear space = **0.5 × 标识高度**（不低于 8px），四周等距；文字/边框/图标不得进入。
- 最小尺寸（按介质）：

| 介质 | 最小 |
|---|---|
| favicon | 16×16（简化版） |
| 应用图标 | 16/24/32 |
| 网页页眉 | 高 ≥ 24 |
| 桌面工具栏 | 高 ≥ 16 |
| 印刷 | 宽 ≥ 10 mm（细线 ≥ 0.25 mm） |
| 刺绣/丝印 | 宽 ≥ 25 mm（去渐变细线） |
| 户外 | 按 1:250 观看距离 |

## 六、响应式标识

三形态：完整组合 → 紧凑（去 tagline / 缩写）→ 纯标识。
阈值建议：可用宽 ≥ 320 完整；160–320 紧凑；< 160 纯标识。降级顺序写进品牌规范，不要临场等比缩小。

## 七、Logo 动效

| 场景 | 参数 |
|---|---|
| 路径绘制 | stroke-dashoffset 600–900ms ease-out |
| 遮罩揭示 | 240–400ms |
| 形态变换 | ≤ 800ms，中间帧 ≥ 12 |
| 悬停微动 | 120–180ms，位移 ≤ 2px |
| 启动动画总时长 | ≤ 1.2s，且仅首次 |
| reduce motion | 仅淡入 ≤ 200ms |

## 八、交付规范

| 项 | 规范 | 检查 |
|---|---|---|
| 描边转轮廓 | 无 stroke，全为填充路径 | 搜索 stroke= 为 0 |
| viewBox | 统一尺寸、无硬编码 width/height | 缩放不变形 |
| 路径精度 | 2 位小数、合并重复点 | 文件 < 20KB |
| 颜色 | token / 命名色板 | hex ≤ 3 个 |
| 安全区 | SVG 内含 ≥ 0.5x 内边距 | 四周等距 |
| 版本 | 彩色/单色/反白/深色 | 缺一不可 |
| 位图 | PNG @1x/2x/3x 透明无投影 | 无灰边 |
| 命名 | brand-mark-color.svg 等，小写连字符 | 统一 |
| 字体 | 转曲或附字体与授权 | 换机不变形 |

## 九、走查清单（12 条）

1. 几何构造说明写清（画板/网格/半径/布尔顺序）
2. 坐标落在 8 点网格或明确比例
3. 圆/三角已做 overshoot
4. 文字已转曲或附授权
5. 安全区 0.5x 四周等距
6. 16px 实测无细节丢失
7. 完整/紧凑/纯标识三形态
8. 浅色/深色/反白/单色四版本
9. 对比 ≥ 3:1（视为非文本）
10. SVG 无描边、viewBox 统一、< 20KB
11. 禁用示例图已出
12. 动效 ≤ 1.2s 且支持 reduce motion
## 十、几何制图法：圆切构造（Pattern of circles）

> 参考：标识制图分「坐标制图法」（方格定位）与「几何制图法」（圆相切求圆心/半径/切点）。圆切线稿的意义是让曲线可证明、可复现。

### 10.1 两种制图法

| 方法 | 做法 | 优点 | 适用 |
|---|---|---|---|
| 坐标制图法 | 方格（4/8/16 单位）定位关键点 | 易复现、硬边准确 | 字母标、像素感 |
| 几何制图法 | 等径/相切圆求圆心、半径、切点 | 曲率可证明、放大不失真 | 有机曲线、动物、抽象标 |

### 10.2 圆切四原则

1. **等径优先**：同一轮廓的圆弧尽量同半径（如两段 R75）。
2. **相切不交叉**：圆与圆只在切点相接，切点必须落在构造线/网格上。
3. **半径成族**：只用 R、R/2、R/3、2R/3、3R/4、1.5R、2R、3R；禁止 R37.4。
4. **可标注**：圆心、半径、切点都能标出，别人能照着重画。

### 10.3 叶片标识实例（可复现）

- 画板 270×220，基准单位 16。
- 圆 A：圆心 (110,110)，R=75；圆 B：圆心 (160,110)，R=75 → 圆心距 d=50。
- 两圆交集 = 叶片轮廓，切点 T1(135,39.3)、T2(135,180.7)。
- 减去圆 C：圆心 (135,176)，R=20 → 底部缺口。
- 成品路径：`M135 39.3 A75 75 0 0 1 135 180.7 A75 75 0 0 1 135 39.3 Z`（+ mask 缺口）。

### 10.4 线稿交付要求

- 保留「构造层 / 标注层 / 成品层」三层（SVG `<g id>` 分组），出图时隐藏构造层。
- 标注内容：圆心点、半径值、圆心距、切点编号、基准网格。
- 半径族校验：所有 r 必须能写成 R 的简单倍数，否则回到画板重算。
- 常见错误：圆与圆交叉而非相切；同轮廓用 3 个不同半径；切点不在网格上；线稿与成品不一致。

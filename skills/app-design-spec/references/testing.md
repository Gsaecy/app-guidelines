# 测试与验收（testing.md）

## 一、上线前 7 项检查

1. **对比度**：正文 ≥ 4.5:1；大字号/图标 ≥ 3:1；深色模式重测（不要凭感觉）。
2. **色觉**：红/绿状态必须配图标或文字；用红色盲、绿色盲滤镜各看一遍。
3. **热区**：触控 44/48，桌面 32×32；相邻可点元素间距 ≥ 8。
4. **键盘**：Tab 顺序 = 视觉顺序；焦点环 2px 可见；Esc 关闭浮层；Enter 触发主操作。
5. **断点**：320 / 600 / 840 / 1200 / 1440 各看一遍；最小宽度无横向滚动。
6. **可读性**：正文 ≥ 12px；行高 1.4–1.7；中文行长 25–40 字。
7. **性能**：单帧 ≤ 16.7ms；列表分批解码；动画只动 transform/opacity。

## 二、WCAG 2.2 AA 清单

- 1.4.3 对比度：正文 4.5:1，大字 3:1
- 1.4.10 重排：320px 宽（400% 缩放）不丢内容、不横向滚动
- 1.4.11 非文本对比：图标/边框/焦点 ≥ 3:1
- 2.4.7 焦点可见：2px 焦点环，偏移 2px
- 2.4.11 焦点不被遮挡：粘性头部/浮层不得覆盖当前焦点
- 2.5.7 拖拽替代：拖拽排序必须提供按钮方式
- 2.5.8 目标尺寸：≥ 24×24 CSS px（推荐 44/48）
- 3.3.7 冗余输入：同一流程不重复索要已填信息
- 3.3.8 无障碍认证：支持粘贴/密码管理器，不做认知测验
- 4.1.2 名称/角色/值：自定义控件必须有 aria 语义

## 三、性能预算

| 指标 | 目标 | 测量 |
|---|---|---|
| 冷启动可交互 | ≤ 2s 桌面 / ≤ 3s 移动 | 启动埋点、DevTools Performance |
| 单帧 | ≤ 16.7ms | Performance / WPF Timeline |
| 首屏图片 | ≤ 12 张，每帧 3–6 张解码 | 缩略图队列 |
| 列表重建 | 数据签名变化才重建 | 集合签名 diff |
| 缩略图缓存 | 300–500 LRU | 内存监控 |
| 图片解码 | 4K JPEG 30–60ms/张，禁止 UI 线程批量 | DecodePixelWidth |
| backdrop-filter | ≤ 3 层同时可见 | Rendering 面板 |
| 长任务 | ≤ 50ms | Long Tasks API |

### 列表页三宗罪（真实案例：299 卡片 4.4GB → 389MB）
1. 事件不按 URL 过滤，每张缩略图触发全部卡片重解码（299² ≈ 9 万次）。
2. 属性变化无差别重建整表。
3. UI 线程同步批量解码图片。
修复：URL 过滤 + 集合签名 diff + 分批解码（每帧 3 张）+ LRU 缓存 + 250ms 防抖。

03Corner Radius

圆角

圆角是最容易「凭感觉」的参数。Windows 只有 4 / 8 两档，Apple 更自由但有嵌套规则，Material 用固定形状刻度。

嵌套规则：外 16 ➜ 内 ≤ 12 ➜ 再内 ≤ 8，相邻圆角差 ≥ 4px，否则看起来像没对齐。同一页面最多 3 种圆角。
04Spacing & Grid

间距与栅格

所有间距都是 4 的倍数；用倍数关系（4 / 8 / 16 / 24 / 32）建立层级，而不是随手写 13px。

间距刻度
场景值（px）
Apple

4pt 基准，布局边距常用 16 / 20，控件内 8 的倍数。

Material 3

8dp 主栅格，允许 4dp 半格；组件内 16dp，屏幕边 16dp。

Windows 11

4px 基准；控件间 4 / 8，区块间 12 / 16 / 24。

05Layout & Breakpoints

布局与响应式

先定窗口与断点，再谈组件。响应式不是「缩小字号」，而是换布局：列数、边距、导航形态一起变。

窗口类宽度典型设备栅格 / 边距布局动作
窗口与容器尺寸
密度模式

行高决定信息密度，不要用 fontSize 压缩。

模式行高适用
硬规则：最小窗口下必须重新排布，而不是出现横向滚动。≥ 1200px 时限制内容最大宽（文字 680–760），否则行长超过 90 字符会显著降低可读性。
导航形态

Compact：底部标签 3–5 个
Medium：侧栏折叠为图标条
Expanded 以上：侧栏常驻 216–280

内容栅格

4 / 8 / 12 列，列间距 16–24
卡片最小宽 240（桌面）/ 160（移动）
同行卡片高度对齐到内容最高者

安全区

移动端避开刘海与手势条（safe-area）
桌面端避开窗口圆角与标题栏按钮
固定底栏需为内容预留同高 padding

05Typography

字号、字重、行高

行高 ≈ 字号 × 1.4–1.5（大标题 1.2，小字 1.5），中文再加 0.05 ⚠️。Windows 一律 sentence case，不用 Title Case。

桌面 App 实用字阶（可直接套用 ⚠️）
Material 3 字阶（sp / 行高）
角色字号行高
Apple 动态字号（pt / 行高 / 字重）
样式字号行高字重
Windows 11 官方字阶（px / 行高 / 字重）
样式字号行高字重用途
硬指标：Windows 正文 14px / 最小 12px；iOS 默认 17pt / 最小 11pt；macOS 默认 13pt / 最小 10pt。一页 ≤ 2 个字重、≤ 3 个字号档。
06Iconography

图标

同组图标必须同源、同描边、同端点。尺寸只用 16 / 20 / 24 / 28，描边随尺寸缩放。

24px 画板 · 2px 描边 · 2px 安全内边距

左：24px 画板 / 2px 描边。
右：同路径缩小到 20px，描边降到 1.5px。
虚线为 12% 安全区。

    08Color

    颜色与对比度

    对比度实时计算：正文 ≥ 4.5:1，大字号与非文本 ≥ 3:1。点击色值可复制。

    中性色最稳的一套：页面底 #F5F5F7、卡片 #FFFFFF、主文字 #1D1D1F、次文字 black α .55、分隔线 black α .08。深色模式用 #000 / #1C1C1E，文字改 white α .94 / .62。
    状态色派生规则

    只定义主色，其余状态靠叠加透明度派生——这样深浅色主题都能自动适配，不需要维护两套色板。

    状态派生方式
    10States & Feedback

    状态与反馈

    界面 80% 的时间不在「正常态」。空、加载、错误、成功、禁用、离线——每种状态都要有出口，不能只写「暂无数据」。

    状态触发时机视觉文案示例禁止
    反馈时长

    Toast：2–4s 自动消失（成功类）
    错误提示：不自动消失，需用户处理
    行内校验：失焦后 200ms 再提示
    进度：< 1s 不显示

    加载形态选择

    已知结构 → 骨架屏
    未知内容 → spinner（≥ 1s 才出现）
    局部更新 → 行内 spinner / 半透明遮罩
    可估算 → 进度条 + 剩余时间

    错误提示位置

    字段级 → 紧贴字段下方，红边框 + 文案
    表单级 → 表单顶部汇总 + 锚点跳转
    页面级 → 内容区中央，含「重试」
    网络级 → 顶部条，保留缓存内容

    10Elevation

    阴影 / 层级

    Apple 偏柔和 + 大扩散；Material 短距离多层叠加；Windows 几乎无阴影，靠 1px 描边分层。悬停卡片看层级 2。

    层级用途ybluralpha
    可直接复制的多层阴影

    近距离小阴影 + 远距离大扩散，比单层大阴影真实得多。点按复制。

    三条经验
    • 阴影不要用纯黑，用 rgba(0,0,0,.06–.22)，深色模式还要更低。
    • 同一屏只保留 2–3 个层级；满屏浮起等于没有层级。
    • Windows 用 1px 描边代替阴影；Apple 才用大扩散柔影。
    11Motion · Lab

    动效（可交互实验室）

    选一条曲线、拖一个时长，点播放看小球怎么走。低于 100ms 视为瞬时，高于 400ms 会觉得卡。

    cubic-bezier(0.22, 1, 0.36, 1)

    横轴时间、纵轴进度。曲线越「陡在中间」越有速度感。

      12Effects Lab

      效果实验室

      程序化效果的「看得见」版本：流场粒子、泛光、暗角、散景，以及壁纸里那套行进波驱动的鱼游模型。

      15Microcopy

      文案规范

      文案是界面的一部分，不是填充物。按钮、错误、空状态各有一套写法，长度也有硬上限。

      场景写法推荐避免
      长度上限
      元素上限超出处理
      大小写规则（Casing）
      平台规则正例反例
      ✓ 推荐

      「壁纸已设为桌面背景」
      「网络不可用，检查连接后重试」
      「还没有收藏，去画廊看看」

      ✗ 避免

      「操作成功！！」
      「出错了」
      「暂无数据」

      13App Structure

      页面结构术语

      沟通时用这些页面名称，90% 的团队成员都能听懂。从启动到反馈，一个 App 的完整页面骨架。

      层级判断：能通过底部标签/侧栏直接到达的是「一级页面」；从一级页面进入、一次返回可回到一级页面的，是「二级页面」。

      19Tools

      工具集

      四个每天都会用到的计算器：对比度、同心圆角、阴影、缓动。结果可直接复制进代码。

      对比度检查器

      小字需 ≥ 4.5:1，大字号（≥ 24px 或 ≥ 18.66px Bold）需 ≥ 3:1。

      壁纸已设为桌面背景
      同心圆角计算器

      内圆角 = max(0, 外圆角 − 内边距)。差值 < 4px 会看起来「没对齐」。

      阴影生成器

      调完直接复制 box-shadow。记住：阴影用半透明黑，不用纯黑。

      Card
      缓动曲线编辑器

      拖滑杆改两个控制点，立即得到 cubic-bezier() 与曲线。超出 0–1 的 y 值会产生回弹。

      令牌导出

      把本页的颜色 / 圆角 / 字号 / 时长导出成 JSON 或 CSS 变量，直接放进工程。

      列表页三宗罪（真实案例）
      
          
      299 张壁纸卡片，内存 4.4GB、UI 假死。定位与修复过程：
      
          
        
            
      1. 事件不按 URL 过滤：每张缩略图落盘都让全部卡片重解码，299² ≈ 9 万次。
        2. 
            
      2. 无差别重建：属性变化就整表重建，299 个卡片对象反复创建。
        3. 
            
      3. UI 线程批量解码：所有缩略图同步解码，主线程被占满。
        4. 
          
      
          
      修复：URL 过滤 + 集合签名 diff + 分批解码（每帧 3 张）+ 420 条 LRU 缓存 + 250ms 防抖 → 内存 389MB，窗口恢复响应。
